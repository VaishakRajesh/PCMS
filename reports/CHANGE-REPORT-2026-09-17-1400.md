## Details
### Scaffold + lib
- `json-db.ts` seeds `vaishak/vaishak123` + `anil/anil123` and two distinct
  portfolios ONLY when files are missing; old single-owner `users.json`
  is renamed to `users.backup-<ts>.json`, never overwritten.
- Auth split deliberately: `session.ts` (jose, Edge-safe for middleware) vs
  `passwords.ts` (bcryptjs, server-only) — importing bcryptjs in middleware
  would break the Edge runtime.
- `[slug]/page.tsx` sanitizes slugs, strict-matches saved `settings.slug`,
  and resolves templates with crash-proof fallback.

### Design + motion
- Modern: gradient blobs, spring avatar, staggered hero, scroll reveals,
  animated skill bars, hover springs, gradient contact band.
- Minimal: zero client JS, CSS `rise` keyframes — proves template switching
  changes real design, not just colors. No login links on public pages.

### Deployment
- Dockerfile builds `output: standalone`, non-root user, volumes for
  `/app/data` + `/app/public/uploads`; README documents VPS deploy,
  persistent-disk requirement, SESSION_SECRET, and why Vercel is unsuitable
  for JSON storage. `render.yaml` still targets Python (repoint = Phase 2).
