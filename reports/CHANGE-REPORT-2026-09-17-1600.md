## Details
### Actions + scoping
- `owner()` guard on every mutation; slug comes from the session only.
- Slug rename moves the JSON file, updates the account + session + saved
  `settings.slug` together (a missed sync here would 404 the new address —
  caught and fixed during validation re-read).
- Errors return via `?error=` redirects; success revalidates dashboard page
  and the public `/{slug}` page. Username uniqueness + lengths enforced.

### Uploads
- Extension + mime + non-empty/5MB + `%PDF` magic bytes; uuid filenames;
  old file removed on replace/delete; `basename()` containment guard.
